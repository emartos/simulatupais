# Guía para agentes — Simula tu país

Lee [el contexto del proyecto](docs/PROJECT-CONTEXT.md) antes de cambiar código, datos o documentación. Consulta `README.md`, `CONTRIBUTING.md` y la documentación específica del área afectada cuando sea pertinente.

Las skills locales están en `.agents/skills/`. Carga solo las que correspondan a la tarea:

| Trabajo | Skill |
|---|---|
| Código TypeScript, JavaScript o CSS | [code-style](.agents/skills/code-style/SKILL.md) |
| Diseño o separación de responsabilidades | [solid-design](.agents/skills/solid-design/SKILL.md) |
| Pruebas unitarias o de regresión | [unit-testing](.agents/skills/unit-testing/SKILL.md) |
| Flujos de navegador | [e2e-testing](.agents/skills/e2e-testing/SKILL.md) |
| Entradas no confiables o superficie de seguridad | [security-review](.agents/skills/security-review/SKILL.md) |
| Motor o resultados económicos | [model-integrity](.agents/skills/model-integrity/SKILL.md) |
| Interfaz y accesibilidad | [accessibility](.agents/skills/accessibility/SKILL.md) |

Respeta los cambios locales. Ajusta el alcance y las verificaciones al encargo concreto. No trates estas guías como autorización para cambiar el modelo, publicar, fusionar o desplegar.
