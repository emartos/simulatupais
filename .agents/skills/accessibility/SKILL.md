# Accesibilidad de interfaz

- Reutiliza componentes y estados existentes. Toda acción visible debe ser operable con teclado, tener nombre accesible y mostrar un estado entendible sin depender solo del color.
- Conserva el orden de lectura y de tabulación en cabeceras, paneles, diálogos, detalles y selector de programas. Los controles móviles deben poder usarse sin desbordamiento horizontal general.
- Mantén al menos 16 px para cuerpo principal y 14 px para texto operativo; reserva tamaños menores para metadatos prescindibles según la jerarquía existente. Comprueba wrapping y zoom del navegador cuando cambie tipografía o layout.
- En gráficos, conserva unidades, leyendas, etiquetas y explicaciones visibles. Un valor aislado no debe obligar a abrir ayuda para entender su unidad.
- Usa WCAG 2.2 AA como referencia para contraste, redimensionado, reflow y espaciado del texto. Valida la pantalla real afectada en desktop y móvil cuando el encargo incluya comprobación visual.
