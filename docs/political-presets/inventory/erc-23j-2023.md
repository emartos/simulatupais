# Inventario programático — Esquerra Republicana de Catalunya (ERC), 23J 2023

Fuente: [programa oficial Eleccions Generals 2023](https://static.esquerra.cat/uploads/20230905/e2023-programa.pdf). Revisión de economía, fiscalidad, derechos sociales, sanidad, educación, vivienda e infraestructuras. El documento formula numerosas reclamaciones para Catalunya/Països Catalans; se separan de propuestas estatales y no se extrapolan.

No se requiere microsimulación fiscal para asignar una dirección programática.
